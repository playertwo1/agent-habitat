# P3.3 — Ponte com o Lumen (leitura local)

**Estado:** Não iniciada. **Checkpoint:** CP-P3.3. **Índice:** [P3](../p3-proximo-ciclo.md).

**Resultado:** com a opção ligada em Ajustes, o Habitat responde um resumo mínimo e somente leitura do estado em `127.0.0.1`, que o Lumen pode consultar. Desligada (padrão), não existe nenhuma porta nova.

**Pré-requisito:** nenhum (recomendado depois de CP-P3.2).

## Contrato proposto (fecha os itens em aberto do questionário)
- **Porta:** a primeira livre da faixa `23433–23437` já usada pelo app, registrada em `~/.agent-habitat/runtime.json` (o Lumen lê a porta de lá).
- **Rota:** `GET /lumen/v1/estado`. Qualquer outro método ou rota responde `405`/`404`.
- **Corpo (JSON):**
```json
{
  "schema": 1,
  "geradoEmMs": 1764115200000,
  "provedores": {
    "claude":  { "fora": true,  "estado": "working", "pendente": false, "sessoes": 2 },
    "codex":   { "fora": false, "estado": "unknown", "pendente": false, "sessoes": 0 },
    "gemini":  { "fora": false, "estado": "done",    "pendente": false, "sessoes": 1 }
  }
}
```
- `estado` ∈ `working | waiting | done | error | unknown`. `unknown` nunca é convertido em `working`. Sem ids de sessão, pastas, prompts nem PIDs.
