# P1.2b — Retomada de sessões do Codex

**Estado:** Implementada em 25/11/2026; falta só a conferência com sessão real no app instalado (P1.2b.3, no fim do P1). **Checkpoint:** CP-P1.2b. **Índice:** [P1](../p1-pos-mvp.md).

**Resultado:** clicar numa sessão recente do Codex no painel a retoma, no CLI ou no app desktop, conforme o que for verificável no Windows.

**Pré-requisito:** CP-P1.2 aprovado. Se o Codex não oferecer retomada confiável, esta fase é **abandonada** e o Codex segue somente leitura.

## Subfases
- [x] **P1.2b.1** Decidir como retomar: investigar o comando real de retomada do Codex CLI e se o app desktop aceita um deep link; registrar a evidência e o que não é possível. (D3) *Evidência:* `codex resume <SESSION_ID>` (codex-cli 0.172.0) aceita o UUID da sessão. Deep link do app desktop não foi investigado nem usado; só o CLI.
- [x] **P1.2b.2** Se viável, implementar a retomada com clique explícito, sem tocar no `~/.codex`. *Evidência:* `src/habitat/habitat-codex-launch.js` (terminal novo com `codex resume <uuid>`, id validado como UUID); o histórico revalida pasta e id antes de abrir. **Limite:** não há sonda de transcrição do Codex; se a sessão não existir mais, o próprio `codex resume` avisa no terminal.
- [x] **P1.2b.3** Testes `T31` verdes (`test/habitat-p1-history.test.js`); conferência pendente (no fim do P1) no app instalado com sessão real do Codex.
